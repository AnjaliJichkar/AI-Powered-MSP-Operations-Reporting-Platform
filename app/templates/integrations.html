How this page decides
  • Set up means a credential for this franchisee exists for that connector. It says nothing about whether the credential still works.
  • Customers mapped is how many of this franchisee's end customers have an organisation mapped on that tool. They are discovered by the site sync and never typed in — except Microsoft 365, where each customer's tenant is mapped by hand, because a directory token cannot enumerate the others.
  • Answering means the most recent read of that tool succeeded, and Failing that every read of it in the window did not. Both are facts about reads we made, not a check run when this page loads; a tool nobody has asked anything of reads as "no reads", which is what it is rather than a verdict on the vendor.
  • The window is the last 30 days. A success in August is not evidence that something works today.
